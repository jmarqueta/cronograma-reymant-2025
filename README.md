# Cronograma de Proyectos

Este repositorio contiene el **cronograma de proyectos (Gantt)** listo para visualizarse online con **GitHub Pages**.

## 🚀 Publicar en GitHub Pages

1. Sube el archivo `index.html` a la raíz de este repositorio (ya está preparado).
2. Ve a **Settings → Pages** en tu repositorio de GitHub.
3. En la sección **Build and deployment**:
   - Source: selecciona **Deploy from a branch**.
   - Branch: elige **main** y folder **/** (root).
4. Guarda los cambios.

Tras unos minutos, GitHub generará un enlace como:
```
https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/
```

## 📂 Contenido
- `index.html`: la aplicación completa en un solo archivo (incluye React, Tailwind y el cronograma).

## 📖 Uso
- Abre el enlace generado por GitHub Pages.
- Podrás añadir proyectos, definir fechas, clientes y estados, y visualizar el cronograma tipo Gantt directamente en tu navegador.
